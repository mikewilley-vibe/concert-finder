# ShowSignal branding

## Public identity

- Name: **ShowSignal**
- Tagline: **Never miss your next show.**
- Background: `#0c0b09`
- Signal lime: `#d8ff3e`
- Warm white: `#f7f4ec`

The icon is an abstract signal mark: two lime arcs orbit a warm-white center
point on a near-black field. It contains no text so it remains recognizable at
small app-icon and favicon sizes.

## Asset locations

- iOS and general Expo icon: `mobile/assets/images/icon.png`
- Android adaptive layers: `mobile/assets/images/android-icon-*.png`
- Splash mark: `mobile/assets/images/splash-icon.png`
- Expo web favicon: `mobile/assets/images/favicon.png`
- Next.js icon and favicon: `app/icon.png` and `app/favicon.ico`

The Apple bundle identifier, Android package, EAS project id, Supabase project,
Vercel domains, API routes, environment-variable names, database names, and
existing storage keys intentionally retain their established internal values.
